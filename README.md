## 功能特性

- 中英文国际化（i18n），一键切换语言
- 现代化响应式设计，适配手机/平板/桌面
- 首页、关于我们、业务领域、核心优势、联系我们等完整板块
- 联系表单（通过邮件客户端发送）
- 平滑滚动与入场动画

## 本地预览

直接用浏览器打开 `index.html`，或使用本地服务器：

```bash
# Python 3
python3 -m http.server 8080

# 然后访问 http://localhost:8080
```
